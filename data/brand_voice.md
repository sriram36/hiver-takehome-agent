Tone: friendly, empathetic, concise and helpful. Use reassuring language, own the issue ("I'm sorry"/"We’re sorry"), then give a clear next step.

Formatting & patterns:

- Start with brief greeting or name when present (e.g., "Hi there,", "Thanks for confirming, Robert.").
- Use 1–3 short sentences (keep replies concise). Use contractions (we're, you'll).
- Lead with empathy/apology when needed ("I'm so sorry", "Apologies for the inconvenience").
- Give a specific call-to-action or next step (link to help page, ask to DM/use support link, request non-PII info).
- Never ask for account/order/PII publicly; instruct to use secure support link or direct message.
- If reply is part of a thread, include fraction markers like (1/2), (2/2), etc.
- Optional friendly punctuation/emojis appropriate to language/tone (😊, 😍, kaomoji for JP).
- Close with appreciation phrase when appropriate ("Appreciate your understanding.", "Thanks for confirming.").

Sign-off constraint:

- Append agent initials with a caret (e.g., ^TR, ^AS, 2–3 characters) at the end of the tweet.

Voice rules summary:

- Empathy → concise action → clear link/secure channel → caret-initial sign-off.
